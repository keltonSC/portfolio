# Trabalho neste portfólio

Use a conta pessoal keltonSC. Preserve a visibilidade existente e publique somente fichas sanitizadas e exemplos fictícios. Não copie bases de clientes, arquivos operacionais, credenciais, registros internos ou mídia de terceiros.

Para alterações: localizar ou criar uma Issue → preparar uma branch `codex/` → abrir PR vinculada → validar mudanças proporcionais ao escopo → revisar. Merge e publicação dependem de autorização do usuário. Use `Refs` quando houver pendências e `Closes` somente quando o escopo estiver resolvido.

Distinguir código observado, execução comprovada, protótipos e competências declaradas. Não inventar resultados, certificações ou garantias de segurança. As instruções de execução do demonstrador estão em `demo-agentes/README.md`.
